> User management and profile system.

## Features

- User registration & authentication
- Profile management
- Avatar upload support
- Role-based access control

## Tech Stack

- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Deploy:** Vercel

## Getting Started

```bash
git clone https://github.com/userclawturk/users.git
cd users
npm install
npm run dev
```
